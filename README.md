# Sales Performance Analysis – Power BI

An interactive Power BI dashboard designed to analyze sales performance, products, territories, shipping, and business insights.

##  Dashboard Preview

![Sales Dashboard](./sales%20dashboard.png)

##  Project Objective

The objective of this project is to analyze sales data and extract meaningful business insights related to:

- Sales performance
- Product performance
- Sales trends
- Customer orders
- Territory performance
- Shipping methods
- Sales targets

##  Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Modeling

##  Key KPIs

- Total Sales: ($2.60B)
- Total Orders: (31.47K)
- Total Freight: ($78.69M)
- Total Tax: ($251.81M)
- Total Due: ($2.93B)
- Target Achievement: (102.38%)

##  Key Insights

- Bikes generated the highest sales among all product categories, reaching approximately ($1.2B).
- Road Bikes were the top-performing products in terms of revenue.
- Sales peaked during the middle of the year, indicating a seasonal demand pattern.
- North America contributed the largest share of total sales.
- The sales target was successfully achieved at (102.38%).
- A relatively small number of products generated a large share of total revenue.

##  Dashboard Pages

The Power BI report includes multiple interactive pages:

- Home / Sales Dashboard
- Products
- Shipping
- Insights Report

The dashboard includes interactive navigation buttons and filters to explore the data dynamically.
